# Discovery Studio Interaction Analysis

Protein–ligand interaction analysis was performed using BIOVIA Discovery Studio Visualizer after molecular docking using the AutoDock Vina wizard implemented in PyRx.
The docked ligand poses were analysed to identify possible intermolecular interactions within the predicted binding pocket of the 7SFB protein structure. Both 2D and 3D interaction visualisations were generated for all selected ligands.

The analysis included interactions such as:

- hydrogen bonding
- hydrophobic interactions
- pi–alkyl interactions
- pi–pi stacking
- van der Waals interactions
- electrostatic interactions

The generated interaction diagrams were used to support the interpretation of docking behaviour and possible ligand stabilisation within the binding region.
