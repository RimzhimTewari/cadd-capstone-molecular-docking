# Discovery Studio Interaction Analysis

Protein–ligand interaction analysis was performed using BIOVIA Discovery Studio Visualizer after molecular docking in PyRx. The docked ligand poses were examined to identify possible interactions inside the predicted binding pocket of the 7SFB protein structure. Both 2D and 3D interaction visualizations were generated for the selected ligands.

The interaction analysis included observations of:

- hydrogen bonds
- hydrophobic interactions
- pi–alkyl interactions
- pi–pi interactions
- van der Waals interactions
- electrostatic interactions

These interaction diagrams helped in understanding how different ligands may interact within the selected binding region.
